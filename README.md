# EventSourcer

Local Codex workspace for Duke and Triangle event discovery. Start with [the master list](Duke_Event_Discovery_Master_List.md), especially its dated access audit and linked source directory.

This folder carries the working files and guidance from the ChatGPT EventSourcer project. The original ChatGPT project and its conversation history remain in ChatGPT; they are not imported as local Codex chat transcripts.

The current [discovery workflow](EventSourcer_Plan.md) covers **next Monday–Sunday, Eastern Time**, unless another window is requested. Work through every relevant active source in the master directory, verify and document all qualifying campus events without a cap, and record source coverage and gaps. Reports show selected events first, new findings, earlier still-upcoming events, any unverified leads/deadlines, source coverage, and a final top-five paragraph. Startup/software/AI/product/builder events lead the unsigned sections.

Use the workspace [duke-campus-events skill](skills/duke-campus-events/SKILL.md); the current project plan supersedes older installed defaults. Save reports under `reports/` and track selections in [Upcoming_Signups.md](Upcoming_Signups.md). Calendar access is checked live when available; calendar holds and organizer registration remain separate. Duke email and paused discovery feeds remain out of scope. The historical semester schedule does not create or change an automation. Browser integration is a separate setup step; these instructions do not install Playwright MCP.
