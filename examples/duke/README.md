# Duke example

A filled-in CampusSift setup for one Duke undergraduate, Fall 2026.

| File | What it is |
|---|---|
| [`profile.md`](profile.md) | Campus boundaries, interests, timetable and preferences |
| [`sources.md`](sources.md) | 121 Duke event sources with a dated access audit |
| [`plan-fall-2026.md`](plan-fall-2026.md) | The original weekly plan this setup grew out of (historical) |
| [`AGENTS.md`](AGENTS.md) | The original standing rules (historical) |

To use it, copy `profile.md` and `sources.md` into a `campussift/` folder in your working directory, then replace the interests and timetable with your own.
